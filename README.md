## 三、主要结果

| 问题 | 关键结果 |
|---|---|
| **一** | 18 架次（C×11 + B×7）、**64.4265 kWh**、**33043.2 s**、最低返航 SOC **20.89%** |
| **二** | 37 架次、makespan **12522.3 s**（较串行缩短 62%）、首批与医疗时限 **100% 满足** |
| **三** | 14 中继架次、总能耗 **70.3003 kWh**、**通信中断 0/609 采样点** |
| **四** | K=2：5 架运输机 + 2 中继（缺 1 架 C 型）；K=3：8 架 + 3 中继（缺 3 架运输机 + 1 架中继） |

**三个反直觉发现**

1. **中继不扩距、只绕障**：`T↔G01` 门限 122 dB / 12.51 km，而 `T↔RA` 仅 116 dB / 6.27 km
   （中继接入端 6 dBi < 网关 12 dBi）。加中继反而把可用距离砍半。
2. **能量是实质约束**：45 个（机型×服务区）组合中 37 个在 ρ≤60% 内受能量约束；
   C 型在 S008 满载往返 SOC = −1.0%（不可行）。
3. **中继需求的机理**：O01 网关在洼地，运输机需飞约 **4 km** 才能越过遮蔽山脊；
   故航线长度 < 遮蔽起始距离 ⇔ 全程可直连（15/15 准确），但存在反例（S004）。

### 唯一的红项（已定性为不可判定项，非缺陷）

`run_global_verify.py` 的 `GR-1`：**±5% 逐箱载荷扰动下方案可行率 63%**。

- **归因**：失效全部集中在 Q1-003（S002）与 Q1-005（S003）两个 C 型远距离架次，
  基准返航 SOC 仅 21.16% / 20.89%。
- **不可改善证明**：两站 67 kg 已是该分区下**最大可装质量**（剩余箱合并后 81 kg > 能量上限 68.13 kg）。
- **影响上界**：载荷高于标称 **3% 以上**时，S002/S003 需降载或增次；其余 16 个架次在 ±5% 扰动下不受影响。
- 已写入 `paper/main.md` §7.4 与 `reports/B8_global.md`。

   Q2/Q3 的结果会变。

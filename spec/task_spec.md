## 1. 问题一：单点往返运输能力与货箱组批

### 1.1 题型定义
- 每架次形态固定为 `O01 → S_i → O01`，**仅服务一个服务区**；同一服务区**可由多个架次**分批服务；**不得跨服务区组批**。
- 本问**不考虑**实体无人机与共享电池调度（架次数不设实体机数量上限）。

### 1.2 判据

| 编号 | 断言 |
|---|---|
| T-1.1 | 单点往返最大安全载荷 `q*_{g,i}`：使 `E_{O→i}(q) + E_{i→O}(0) ≤ (1-ρ_g)E_g^use` 的最大 `q`；同时报告 `min(Q_g, V_g·密度, q*_能量)` 的**瓶颈归属** |
| T-1.2 | 每架次总质量 ≤ `Q_g` |
| T-1.3 | 每架次总体积 ≤ `V_g` |
| T-1.4 | 每架次 `E_p^T ≤ (1-ρ_g)E_g^use` |
| T-1.5 | 每个货箱恰好被一个架次承运；所有 80 箱必须交付 |
| T-1.6 | 架次内货箱必须同属一个服务区 |
| T-1.7 | 架次往返时间 = `τ_prep + τ_box·n + Σ航段 t + (τ_hand0 + τ_hand1·n)`（D5） |

### 1.3 第(2)问 —— 货箱组批
在 T-1.2..T-1.4、T-1.6 下确定各服务区的货箱→架次划分。**目标为可行**（第(2)问只需给出组批方案），并在第(3)问中优化。

### 1.4 第(3)问 —— 三指标优化
| 编号 | 断言 |
|---|---|
| T-1.8 | 完成全部 80 箱交付（不可放弃箱） |
| T-1.9 | 三指标：**总架次数** `F^sortie`、**总运输能耗** `F^E`、**累计作业时间** `F^T` |
| T-1.10 | `F^T` 定义 = 各架次往返时间之和（本问无并行，故等于串行总时长） |
| T-1.11 | 必须给出 **Pareto 前沿**，不得只给单一加权解 |
| T-1.12 | 必须明确三指标的**权衡关系或优先关系**（题面要求"说明"） |

### 1.5 第(4)问 —— 返航安全余量影响
| 编号 | 断言 |
|---|---|
| T-1.13 | 扫描 `ρ ∈ {0,5,10,15,20,25,30}%`，输出"最大安全载荷—ρ"与"组批结果—ρ" |
| T-1.14 | 必须给出**临界 ρ**（超过此值能量项才开始约束载荷） |
| T-1.15 | 若组批结果在某 ρ 区间不变，必须解释原因（实测预示瓶颈为几何，见 E9） |

## 2. 问题二：异构无人机多点多架次运输调度

### 2.1 题型定义
- 每架次可访问**一个或多个**服务区，交付后返回 O01。
- 引入实体无人机（8 架）、共享电池池（A:6/B:4/C:4）、充电周转、物资时限。

### 2.2 判据

| 编号 | 断言 |
|---|---|
| T-2.1 | 继承 T-1.2..T-1.6、T-1.7 |
| T-2.2 | 每个架次必须绑定**一个实体无人机** `u_p`，且 `机型(u_p) = g_p` |
| T-2.3 | 每个架次必须绑定**一组该机型的共享电池** `k_p` |
| T-2.4 | 同一实体无人机的同时段不得执行两个架次 |
| T-2.5 | 同一电池的同时段不得被执行任务与充电**重叠占用** |
| T-2.6 | 同机型同时占用的电池组数 ≤ 该机型库存 |
| T-2.7 | 电池充电：任务结束后按 `t_chg(s_end)` 充电至 100% 方可再次投入 |
| T-2.8 | **首批硬约束**：`是否首批保障=是` 的 30 箱，交付时刻 ≤ 其 `首批截止时间` |
| T-2.9 | **医疗硬约束**：医疗物资交付时刻 ≤ 其 `期望送达时间`（D9 修正） |
| T-2.10 | 其他物资期望时间按**加权迟延**计入 `F^time`，权重 = `应急优先系数` |
| T-2.11 | `F^done` = 所有运输无人机完成最后一个架次并返回 O01 的**最晚时刻** |
| T-2.12 | 多服务区架次中，每次投送后从服务区作业高度重新爬升（D6） |
| T-2.13 | 架次访问顺序中，服务区不重复；首尾为 O01 |
| T-2.14 | 必须给出路线、架次安排、**逐箱送达时刻**、无人机与电池资源使用情况 |
| T-2.15 | 必须**检验方案资源可行性**（题面要求） |

## 3. 问题三：通信约束下的运输与中继联合调度

### 3.1 题型定义
- 运输机在**爬升、巡航、下降、投送**四阶段均须保持连续通信（D7）。
- 直连不可用时可由**一架**中继提供两段链路；**不允许中继之间多跳**。
- 每架运输机在任一时刻只能由 G01 **或一架**中继保障。

### 3.2 判据

| 编号 | 断言 |
|---|---|
| T-3.1 | 继承 T-2.1..T-2.15 全部 |
| T-3.2 | **零通信中断**：每个运输架次的每一时刻，通信状态 ∈ {直连, 中继} |
| T-3.3 | 直连判定：`A_{T↔G01}(t) = 1` |
| T-3.4 | 中继判定：`A_{T↔RA}(t) = 1` **且** `A_{RB↔G01}(t) = 1`（同一时刻**同时**可用） |
| T-3.5 | 中继悬停位置必须在 DEM 覆盖范围内 |
| T-3.6 | 中继悬停离地高度 `H_r ≤ 300 m`（D8 约束）；填报"悬停海拔"为**绝对海拔** |
| T-3.7 | 中继由 O01 出发 → 悬停建链 → 服务 → 返回 O01；满足返航电量 |
| T-3.8 | 中继时间 = `τ_prep + 去程飞行 + τ_link`（建链完成）…`服务结束 + 回程飞行`，架次间 `τ_turn` |
| T-3.9 | 中继能耗 = 水平巡航（`P_cruise`）+ 爬升附加 + 悬停（`P_hover + P_comm`）× 服务时长 |
| T-3.10 | 同一中继无人机的同时段不得执行两个中继架次；能源组件同 T-2.5/T-2.6/T-2.7 |
| T-3.11 | `F^done,joint` = 运输机与中继机**均**完成最后架次返回 O01 的最晚时刻 |
| T-3.12 | 四指标：配送及时性、联合完成时间、运输+中继总能耗、两类无人机使用架次 |
| T-3.13 | 必须给出运输与中继联合调度方案 + 货箱交付 + 资源使用 + 通信保障情况 |

## 4. 问题四：救援任务分区与资源配置优化

### 4.1 判据

| 编号 | 断言 |
|---|---|
| T-4.1 | 15 个服务区划分为 **K=2** 和 **K=3** 个任务组 |
| T-4.2 | 每个服务区**恰好属于一个**任务组 |
| T-4.3 | 每个任务组**至少含一个**服务区 |
| T-4.4 | 保持 Q3 已确定的货箱组批、访问顺序、运输与中继任务安排、通信保障关系**不变** |
| T-4.5 | 若同一运输架次涉及多个服务区 → 这些服务区**必须**划入同一任务组（等价类约束，D12） |
| T-4.6 | 各任务组仅承担本组任务；**资源不得跨组调配** |
| T-4.7 | 分别核算各组所需的 A/B/C 运输无人机数、A/B/C 电池组数、中继无人机数、中继能源组件数 |
| T-4.8 | 与现有库存（A:6/B:4/C:4 电池；运输机 4/2/2；中继机 2；中继组件 6）对账，给出**冗余**与**缺口** |
| T-4.9 | 比较维度：资源配置规模、资源冗余、组间工作量均衡、与库存的资源缺口 |
| T-4.10 | 若某方案超库存，给出**缺口及其原因** |

# 评分要点 Rubric（自建）

> 用于**自查是否达到获奖论文的完成度**，以及 ⑥评审阶段逐项打分。
> 每项 0–3 分；**总分 < 80% 不得进入 B10 论文写作**。

## R1 结果完整性（权重 25%）

| 项 | 3 分标准 | 判据 |
|---|---|---|
| R1.1 表完整性 | 6 个提交表全部生成，列名逐字符对齐模板 | T-5.1 |
| R1.2 覆盖 | 80 箱全部交付且唯一 | T-1.5 |
| R1.3 数值完整 | 无空值/NaN，能耗与 SOC 位数合规 | T-5.3..T-5.5 |
| R1.4 四问齐全 | Q1 四小问、Q2 两小问、Q3 两小问、Q4 两小问全部作答 | 题面逐条 |

| 项 | 3 分标准 | 判据 |
|---|---|---|

## R6 诚实性（权重 —— 一票否决项）

| 项 | 判据 |
|---|---|
| R6.1 | 未决口径必须在论文"适用条件"中显式声明 |
| R6.2 | 不可判定项必须给出**影响上界**（"最坏使指标恶化 X%"） |
| R6.3 | 禁止把"不可判定"降级为"低优先级"后静默跳过 |
| R6.4 | 禁止在 `out/` 中手工填写任何数字 |
| R6.5 | 卡线解（落在判据 1% 邻域）必须标注为脆弱解 |

> **一票否决**：发现任何一项违反 → 总分归零，回灌③重做。

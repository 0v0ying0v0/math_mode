# 问题注册表 (Problem Registry)

> **目的**：回答"提出了几个问题"必须可审计。**每个问题一经提出即获唯一 ID，永不删除**。
> 状态只允许向 `已裁决` 迁移；若要推翻，必须新开一条问题并注明 `supersedes: P-xx`。
> 对应 `spec/iteration_ledger.md` §1。

## 问题计数口径

| 计数 | 含义 | 用途 |
|---|---|---|
| **N_raised** | 累计提出问题总数（含已关闭） | 回答"提出了几个问题" |
| **N_open** | 状态 ≠ 已裁决 | 必须为 0 才允许写论文（终止保护除外） |
| **N_blocking** | 严重度 ∈ {阻断, 高} | 每个都要求 ≥2 个候选解（账本 §3） |
| **N_by_origin** | 按来源分组：自检/数据验证/红队/评审 | 看哪条防线最有效 |
| **N_by_type** | 按类型分组：口径/建模/实现/数据 | 口径类多 → 回灌①；实现类多 → 回灌③ |

## 问题生命周期状态机

```
        提出
         │
         ▼
      ┌──────┐   验证手段无法判定   ┌──────────┐
      │ 待验 │────────────────────►│ 不可判定 │──┐
      └──┬───┘                     └──────────┘  │
         │ 验证证实/证伪                          │ 必须在论文"适用条件"
         ▼                                        │ 中显式声明 + 给出影响上界
      ┌────────┐                                  │
      │ 已验证 │                                  │
      └──┬─────┘                                  │
         │ 作出选择并写入 decisions.md            │
         ▼                                        │
      ┌────────┐                                  │
      │ 已裁决 │◄─────────────────────────────────┘
      └────────┘   （不可判定项若后续获得新证据，可回到 已验证）
         │
         │ 若被推翻 → 新开 P-yy (supersedes: P-xx)，旧条目标注"已被 P-yy 取代"
         ▼
      ┌────────┐
      │ 已取代 │
      └────────┘
```
